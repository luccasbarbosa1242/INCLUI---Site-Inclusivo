## 📋 Sobre el proyecto

Este sitio web cuenta con un **sistema de navegación y lectura mediante comandos de voz**, permitiendo al usuario navegar entre los temas y controlar algunas funciones de la página mediante la voz.

Al hacer clic en el botón **"Comenzar a leer"**, el agente de voz se activa y comienza a leer la página desde el inicio.

---

# 🚀 Cómo ejecutar

## 🐧 Linux

<details>
<summary><strong>▶ Ver instrucciones para Linux</strong></summary>

<br>

### 1. 📥 Descarga el archivo

Descarga el siguiente archivo:

```text
index.html
```

### 2. 📁 Crea o selecciona una carpeta

Coloca el archivo `index.html` dentro de una carpeta de tu preferencia.

### 3. 💻 Abre la terminal

Abre la carpeta que contiene el archivo.

Haz clic derecho dentro de la carpeta y selecciona:

> **Abrir en la Terminal**

### 4. ▶️ Inicia el servidor local

Ejecuta el siguiente comando:

```bash
python3 -m http.server 8000
```

### 5. 🌐 Abre el sitio web

Abre **Google Chrome** y accede a:

```text
http://localhost:8000
```

### 6. 🎤 Concede los permisos

Cuando se solicite, concede los permisos necesarios para que el sistema de comandos de voz pueda funcionar correctamente.

### 7. 🎉 ¡Listo!

Ahora puedes utilizar el sitio web normalmente.

</details>

# 🎙️ Comandos de Voz

El sitio web incluye comandos de voz para facilitar la navegación y el control de la página.

> [!TIP]
> Haz clic en el botón **"Comenzar a leer"** para activar el agente de voz y comenzar a leer la página desde el inicio.

## 🗣️ Comandos disponibles

| 🎙️ Comando | ⚡ Función |
|---|---|
| `Cambiar tema` | Cambia el tema actual |
| `Leer tema 1` | Lee el tema 1 |
| `Leer tema 2` | Lee el tema 2 |
| `Leer tema 3` | Lee el tema 3 |
| `Leer tema 4` | Lee el tema 4 |
| `Ir al final de la página` | Va al final de la página |
| `Volver al inicio` | Regresa al inicio de la página |
| `Cambiar tema visual` | Cambia el tema de la página |
| `Tema claro` | Activa el tema claro |
| `Tema oscuro` | Activa el tema oscuro |

---

# 🔊 Lectura por Voz

Al hacer clic en:

> **🎙️ Comenzar a leer**

el agente de voz se activa y comienza a leer la página desde el inicio.

Durante el uso, los comandos de voz pueden utilizarse para navegar entre los temas y controlar las funciones disponibles.
