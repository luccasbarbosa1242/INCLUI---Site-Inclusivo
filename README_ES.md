Instrucciones de Uso
¡IMPORTANTE!
El sitio web funciona mejor localmente utilizando Google Chrome, por lo que recomendamos utilizar este navegador al probar el sitio.

Idiomas:
[🇧🇷 Português](README.md) · [🇺🇸 English](README_EN.md) · 🇪🇸 Español
🐧 Linux
1. Descarga el archivo index.html.
2. Coloca el archivo en una carpeta de tu preferencia.
3. Abre la carpeta que contiene el archivo.
4. Haz clic derecho dentro de la carpeta y selecciona "Abrir en la Terminal".
5. Escribe el siguiente comando:
python3 -m http.server 8000
6. Abre el navegador.
7. Accede a:
localhost:8000
8. Concede los permisos solicitados.
9. ¡Utiliza el sitio web!
🪟 Windows
1. Descarga el archivo index.html.
2. Abre el navegador e instala Visual Studio Code (VS Code).
3. En VS Code, accede a la pestaña Extensiones.
4. Instala la extensión Live Server.
5. Abre el archivo index.html en VS Code.
6. Haz clic derecho en el archivo dentro de VS Code.
7. Selecciona "Open with Live Server".
8. Concede los permisos solicitados.
9. ¡Disfruta del sitio web!
🎙️ Comandos de Voz
El sitio web cuenta con comandos de voz para facilitar la navegación.
Algunos de los comandos disponibles son:
- "Cambiar tema" — cambia el tema.
- "Leer tema 1" — lee el tema 1.
- "Leer tema 2" — lee el tema 2.
- "Leer tema 3" — lee el tema 3.
- "Leer tema 4" — lee el tema 4.
- "Ir al final de la página" — va al final de la página.
- "Volver al inicio" — regresa al inicio de la página.
- "Cambiar tema visual" — cambia el tema de la página.
- "Tema claro" — activa el tema claro.
- "Tema oscuro" — activa el tema oscuro.
Al hacer clic en el botón "Comenzar a leer", el agente de voz se activa y comienza a leer la página desde el inicio.
