## 📋 About the project

This website features a **voice-based navigation and reading system**, allowing users to navigate between topics and control some page functions using voice commands.

By clicking the **"Start Reading"** button, the voice agent is activated and starts reading the page from the beginning.

# 🚀 How to run

## 🐧 Linux

<details>
<summary><strong>▶ View Linux instructions</strong></summary>

<br>

### 1. 📥 Download the file

Download the following file:

```text
index.html
```

### 2. 📁 Create or choose a folder

Place the `index.html` file inside a folder of your choice.

### 3. 💻 Open the terminal

Open the folder containing the file.

Right-click inside the folder and select:

> **Open in Terminal**

### 4. ▶️ Start the local server

Run the following command:

```bash
python3 -m http.server 8000
```

### 5. 🌐 Open the website

Open **Google Chrome** and go to:

```text
http://localhost:8000
```

### 6. 🎤 Grant permissions

When prompted, grant the necessary permissions so the voice command system can work properly.

### 7. 🎉 Done!

You can now use the website normally.

</details>

# 🎙️ Voice Commands

The website includes voice commands to make navigation and page control easier.

> [!TIP]
> Click the **"Start Reading"** button to activate the voice agent and start reading the page from the beginning.

## 🗣️ Available commands

| 🎙️ Command | ⚡ Function |
|---|---|
| `Change topic` | Changes the current topic |
| `Read topic 1` | Reads topic 1 |
| `Read topic 2` | Reads topic 2 |
| `Read topic 3` | Reads topic 3 |
| `Read topic 4` | Reads topic 4 |
| `Go to the end of the page` | Goes to the end of the page |
| `Go back to the beginning` | Returns to the beginning of the page |
| `Change theme` | Switches the page theme |
| `Light theme` | Activates the light theme |
| `Dark theme` | Activates the dark theme |

# 🔊 Voice Reading

By clicking:
