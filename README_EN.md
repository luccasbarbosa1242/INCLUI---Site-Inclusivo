Usage Instructions
IMPORTANT!
The website works best locally when using Google Chrome, so we recommend using this browser when testing the website!

Languages:
[🇧🇷 Português](README.md) · 🇺🇸 English · [🇪🇸 Español](README_ES.md)
🐧 Linux
1. Download the index.html file.
2. Place the file in a folder of your choice.
3. Open the folder containing the file.
4. Right-click inside the folder and select "Open in Terminal".
5. Type the following command:
python3 -m http.server 8000
6. Open your browser.
7. Go to:
localhost:8000
8. Grant the requested permissions.
9. Use the website!
🪟 Windows
1. Download the index.html file.
2. Open your browser and install Visual Studio Code (VS Code).
3. In VS Code, open the Extensions tab.
4. Install the Live Server extension.
5. Open the index.html file in VS Code.
6. Right-click the file inside VS Code.
7. Select "Open with Live Server".
8. Grant the requested permissions.
9. Enjoy the website!
🎙️ Voice Commands
The website includes voice commands to make navigation easier.
Some of the available commands are:
- "Change topic" — changes the topic.
- "Read topic 1" — reads topic 1.
- "Read topic 2" — reads topic 2.
- "Read topic 3" — reads topic 3.
- "Read topic 4" — reads topic 4.
- "Go to the end of the page" — goes to the end of the page.
- "Go back to the beginning" — returns to the beginning of the page.
- "Change theme" — switches the page theme.
- "Light theme" — activates the light theme.
- "Dark theme" — activates the dark theme.
By clicking the "Start Reading" button, the voice agent is activated and starts reading the page from the beginning.
