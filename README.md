Instruções de Uso
IMPORTANTE!
O site funciona melhor localmente utilizando o Google Chrome, então dê preferência a esse navegador ao testar o site!

Idiomas:
🇧🇷 Português · [🇺🇸 English](README_EN.md) · [🇪🇸 Español](README_ES.md)
🐧 Linux
1. Baixe o arquivo index.html.
2. Coloque o arquivo em uma pasta de sua preferência.
3. Abra a pasta que contém o arquivo.
4. Clique com o botão direito dentro da pasta e selecione "Abrir no Terminal".
5. Digite o seguinte comando:
python3 -m http.server 8000
6. Abra o navegador.
7. Acesse:
localhost:8000
8. Conceda as permissões solicitadas.
9. Utilize o site!
🪟 Windows
1. Baixe o arquivo index.html.
2. Abra o navegador e instale o Visual Studio Code (VS Code).
3. No VS Code, acesse a aba Extensões.
4. Instale a extensão Live Server.
5. Abra o arquivo index.html no VS Code.
6. Clique com o botão direito no arquivo dentro do VS Code.
7. Selecione "Open with Live Server".
8. Conceda as permissões solicitadas.
9. Aproveite o site!
🎙️ Comandos de Voz
O site possui suporte a comandos de voz para facilitar a navegação.
Alguns dos comandos disponíveis são:
- "Troca tópico" — troca o tópico.
- "Ler tópico 1" — lê o tópico 1.
- "Ler tópico 2" — lê o tópico 2.
- "Ler tópico 3" — lê o tópico 3.
- "Ler tópico 4" — lê o tópico 4.
- "Ir para o final da página" — vai para o final da página.
- "Voltar ao início" — retorna ao início da página.
- "Trocar tema" — alterna o tema da página.
- "Tema claro" — ativa o tema claro.
- "Tema escuro" — ativa o tema escuro.
Ao clicar no botão "Começar a ler", o agente de voz é ativado e começa a ler a página desde o início.
