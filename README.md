Instruções de uso:
IMPORTANTE!!
O site funciona melhor localmente se o seu navegador for o google chrome, então dê preferencia para este navegador ao testar o site!

Caso seu sistema seja linux:
Baixe o arquivo index.html
Coloque em uma pasta de sua preferencia
Abra a pasta com o arquivo dentro
Clique com botão direito e abra a pasta no terminal
digite:
python3 -m http.server 8000
Abra seu navegador
Digite:
localhost:8000
Aperte enter
De a permissão
Utilize o site!
Ele acompanha comandos de voz para passar a página (Troca tópico, ler tópico 1, 2, 3 e 4, ir para o final da página, voltar ao ínicio, trocar tema, tema claro, tema escuro). Ao clicar no botão "começar a ler" o agente de voz é ativado e começa a ler a página desde o ínicio.

Caso seu sistema seja windows:
Baixe o arquivo index.html
Abra o navegador e instale o VScode
No VScode entre na aba extensões e instale a extensão Live Server
Abra o arquivo index.html no vscode
Clique com o botão direito no arquivo dentro do VScode e selecione "open with live server"
Aproveite o site!
