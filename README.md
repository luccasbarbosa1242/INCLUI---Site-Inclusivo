## 📋 Sobre o projeto

Este site possui um sistema de **navegação e leitura por comandos de voz**, permitindo que o usuário navegue pelos tópicos e controle algumas funções da página utilizando a voz.

Ao clicar no botão **"Começar a ler"**, o agente de voz é ativado e começa a realizar a leitura da página desde o início.

# 🚀 Como executar

## 🐧 Linux

<details>
<summary><strong>▶ Ver instruções para Linux</strong></summary>

<br>

### 1. 📥 Baixe o arquivo

Baixe o arquivo:

```text
index.html
```

### 2. 📁 Crie ou escolha uma pasta

Coloque o arquivo `index.html` dentro de uma pasta de sua preferência.

### 3. 💻 Abra o terminal

Abra a pasta que contém o arquivo.

Clique com o botão direito dentro da pasta e selecione:

> **Abrir no Terminal**

### 4. ▶️ Inicie o servidor local

Digite o seguinte comando:

```bash
python3 -m http.server 8000
```

### 5. 🌐 Abra o site

Abra o **Google Chrome** e acesse:

```text
http://localhost:8000
```

### 6. 🎤 Conceda as permissões

Quando solicitado, conceda as permissões necessárias para que o sistema de comandos de voz possa funcionar.

### 7. 🎉 Pronto!

Agora você pode utilizar o site normalmente.

</details>

# 🎙️ Comandos de Voz

O site possui comandos de voz para facilitar a navegação e o controle da página.

> [!TIP]
> Clique no botão **"Começar a ler"** para ativar o agente de voz e iniciar a leitura da página desde o início.

## 🗣️ Comandos disponíveis

| 🎙️ Comando | ⚡ Função |
|---|---|
| `Troca tópico` | Troca o tópico atual |
| `Ler tópico 1` | Lê o tópico 1 |
| `Ler tópico 2` | Lê o tópico 2 |
| `Ler tópico 3` | Lê o tópico 3 |
| `Ler tópico 4` | Lê o tópico 4 |
| `Ir para o final da página` | Vai para o final da página |
| `Voltar ao início` | Retorna ao início da página |
| `Trocar tema` | Alterna o tema da página |
| `Tema claro` | Ativa o tema claro |
| `Tema escuro` | Ativa o tema escuro |

---

# 🔊 Leitura por Voz

Ao clicar em:

> **🎙️ Começar a ler**

o agente de voz é ativado e começa a realizar a leitura da página desde o início.

Durante a utilização, os comandos de voz podem ser utilizados para navegar entre os tópicos e controlar as funções disponíveis.
